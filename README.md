# alfasportfolio

Portfolio of Mohammed Alfas K (DeRpot), a BCA third-year student at Primus B School, Bangalore, and a freelance vibe coder.

## Projects

- CareerGenie — career exploration and planning.
- CB Verify — a verification workflow tool.
- CB Daily — a tool for daily business operations.
- Credit Management System — credit records and balance tracking.
- Chick Buck Website — a restaurant website and online ordering experience.

## Run locally

Open `index.html` in a browser, or serve the folder with a local static web server.

The site uses plain HTML, CSS and JavaScript. Edit `mohammed-content.js` for portfolio text and project details, `styles.css` for presentation, and `script.js` for interactions.
